Privacy & Local Processing

This website loads no analytics, external fonts or tracking scripts and has no account or payment form. GitHub hosts the website and downloads; requests to GitHub are subject to its own privacy practices.

Excel analysis

Current analytical workflows run locally through desktop Excel. Telivu does not require workbook uploads to an analytics service. Your workbook may independently use external data connections.

Local application state

The current activation-free release neither read nor write product activation state. Old user activation data is ignored and left untouched. Diagnostic logs are stored locally.

Public issue reports

GitHub issues are public. Use synthetic models and remove business information before reporting an issue.
