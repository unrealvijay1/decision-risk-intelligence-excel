Getting Started

System requirements

Windows 10 22H2 or Windows 11 and desktop Microsoft Excel. Both x86 and x64 packages are built; the installer detects Excel architecture. Native ARM64 Excel is unsupported. Excel for Mac and Excel in a browser are unsupported.

Install safely

Save your work and close all Excel windows before running Setup. The current release is unsigned, so Windows may display a publisher warning. Obtain it only through the official Download button. Setup installs per user and registers the add-in; missing .NET Desktop Runtime prerequisites may require administrator permission.

First simulation

  1. Create a blank workbook. Enter 100 in A2 and =A2*10 in B2.
  2. Select A2 and choose Define Assumption. Choose Normal with mean 100 and standard deviation 10.
  3. Select B2 and choose Define Forecast. Give the output a useful name.
  4. Choose Simulation Settings and set a fixed seed for reproducible exploration, then Run Simulation.
  5. Review Results, try a target of 1,100, and export a report. Save the workbook to retain model definitions.

If the add-in does not appear

Confirm Setup completed, restart Excel, and check Excel Options → Add-ins. Close Excel before reinstalling. Do not change another add-in’s registration. Report failures with Excel architecture, Windows version and the exact error text on GitHub.

Available release access

Version 0.2.1 retains legacy trial and activation checks. Development builds remove those checks, but the existing public asset is preserved until a new release is authorized.
