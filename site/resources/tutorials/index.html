Tutorials

Interpret a percentile

For a cost forecast, P80 is a cost at or below which approximately 80% of simulated outcomes fall. A larger percentile is generally a more conservative budget. For benefits, interpret the direction differently.

Ask a target question

After simulation, choose a forecast and a target. Use the correct direction: at or below for a cost ceiling, at or above for a revenue goal. Results depend on assumptions and model quality.

Compare a decision

Create scenario adjustments, select a baseline and run the comparison. Review both outcome differences and target probabilities. Common streams reduce sampling noise between scenarios.

Make runs reproducible

Save model definitions and settings, set a fixed seed, and retain the exported report. Changing a model or assumptions changes the result even when the seed stays the same.
