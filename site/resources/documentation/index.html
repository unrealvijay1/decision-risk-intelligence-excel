Documentation

Monte Carlo simulation

Define uncertain input cells and formula forecasts. Fourteen distributions are supported: Normal, Triangular, PERT, Uniform, Lognormal, Beta, Exponential, Poisson, Binomial, Discrete, Weibull, Gamma, Bernoulli and Truncated Normal. Historical-data fitting supports Normal, Lognormal, Uniform and Triangular.

Results and sensitivity

Review forecast summary statistics, distribution and cumulative probability charts, percentile markers and target calculators. Sensitivity ranks associations between uncertain assumptions and forecast results; it does not establish causation. Export Report is available inside Results.

Correlations

Configure dependence between assumptions using the Correlations editor. Invalid correlation matrices are rejected. Review the intended relationships and marginal distributions before running a model.

Scenario Analysis

Compare base, upside, downside or custom assumption adjustments with common random streams. Configure a comparison baseline and target direction to interpret probability and outcome differences consistently.

Optimizer

Define decision cells, bounds and step sizes, an objective and constraints. Deterministic evaluation works without assumptions; simulation-aware evaluation uses trial outcomes. Constraint-aware iterative search returns the best feasible candidate it finds, without guaranteeing a global optimum. Review results before explicitly applying decisions.

Statistical process control

Use SPC Analysis for ordered observations, XmR charts, fixed baselines and five Wheeler special-cause rules. Keep baseline selection independent of desired targets. Investigate signals in process context; a signal is not a diagnosis.

Workbook persistence

Save the workbook to retain definitions and settings. Reload Model refreshes the current workbook model. Clear Cell Definition removes a selected definition; Clear Model removes model definitions. Back up workbooks before clearing or applying decisions.
