FROM DOWNLOAD TO YOUR FIRST RESULT

Start with a model you understand.

1. Install

Close Excel, download the existing Windows installer and run it. Setup detects Excel architecture and installs the matching add-in. The package includes the required .NET desktop runtime; installing a missing runtime may request administrator access.

2. Define

Open Excel. Use Define Assumption on an uncertain input and Define Forecast on a formula output. Start with a small, unprotected workbook and save a backup before analysis.

3. Run and learn

Choose Simulation Settings, then Run Simulation. Review percentiles, target probabilities and sensitivity. Export Report from Results to record the analysis.

A FEW USEFUL ANSWERS

Before you
get started.

Does Telivu replace Excel?

No. Telivu extends Microsoft Excel with decision-analysis capabilities.

Do I need to know programming?

No. Configure assumptions, forecasts and analysis through the add-in’s interface.

Does it work with my existing Excel model?

Telivu is designed for Excel-based models. Inputs, forecasts and references must meet supported configuration requirements. Workbook protection, external dependencies and calculation behavior may affect compatibility.

Does Telivu support 32-bit and 64-bit Excel?

Both x86 and x64 packages are built. Final clean-machine validation for both Excel architectures remains a release gate; the available installer is an unsigned prerelease. Windows is required.

Does Telivu upload my workbook?

Current analysis runs locally through Excel on your computer. Workbook data is not uploaded to an analytics service. Current licensing also uses local offline validation.

Is the current installer unrestricted?

Development builds now run without activation. The existing 0.2.1 installer retains its 30-day trial and activation checks. Publishing an activation-free release and approving the legal open-source license are separate owner decisions.

Is Telivu an AI tool?

Telivu is a quantitative decision-analysis tool. Its core simulation, optimization and statistical methods produce analytical results rather than relying on generative AI. Fixed seeds support reproducible simulations under the same model and settings.
